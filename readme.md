# Points TD 2

A fast, colorful (pixel-art) tower-defense experience with bite-sized waves, multiple enemy types, and a variety of towers to master. Place towers, upgrade them, and defend your base from inventive special enemies in handcrafted maps.

Play a polished single‑player experience with:
- Tight, arcade-style wave gameplay and meaningful upgrades
- Unique enemy specials (gold, lead, anti_explosion, stack, stack+, stack++, regeneration)
- Variety of towers: sniper, bomber, ninja, magician, machine gunner, bank, spikes, particle accelerator and more
- (Map editor and wave tool so you can create and share custom content)

## Quick start
- Run the game: see [main.py](main.py)

## Controls (default)
- Place / select towers: mouse
- Start next wave: Space or mouse-click on the button
- Toggle fullscreen: F11
- (Debug overlays: F1 / F2 / F3)


## Modding
- Add or tweak towers in the [towers/](towers/) folder
- Customize enemy waves in [waves/](waves/) with [wave_converter.py](wave_converter.py)
- Edit maps with [map_editor.py](map_editor.py)
